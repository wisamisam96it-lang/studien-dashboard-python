Dashboard zur Überwachung des Studienfortschritts

Projektbeschreibung

Dieses Projekt wurde im Rahmen des IU-Portfolios
„Objektorientierte und funktionale Programmierung mit Python“
entwickelt.

Der Prototyp unterstützt die Überwachung des individuellen
Studienfortschritts im Studiengang Medizininformatik.

Funktionen

- Anzeige des aktuellen Notendurchschnitts
- Berechnung des ECTS-Fortschritts
- Berechnung des Studienfortschritts
- Countdown bis zum Semesterende
- Hinzufügen von Modulen
- Bearbeiten von Modulen
- Löschen von Modulen
- Speicherung aller Daten in JSON-Dateien

Projektstruktur

- models.py → Entity-Klassen
- repository.py → Datenpersistenz
- service.py → Geschäftslogik
- controller.py → Benutzeroberfläche
- main.py → Programmeinstieg

Verwendete Technologien

- Python 3.12
- JSON
- GitHub
- Visual Studio Code

Programmstart

`bash
python main.py
